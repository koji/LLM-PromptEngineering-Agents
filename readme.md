# Awesome LLM Agents

Curated links for ChatGPT, LLMs, prompt engineering, agent frameworks, coding tools, libraries, and adjacent resources.

**Browse it:** [koji.github.io/awesome-llm-agents](https://koji.github.io/awesome-llm-agents/) — searchable and filterable, organized by category.

## Structure

- `readme.md`: entry point and category index.
- `data/entries.yml`: source of truth for all resource entries.
- `scripts/generate.py`: regenerates category pages and builds the browse site (stdlib only).
- `docs/categories/`: category pages (generated — do not edit by hand).
- `docs/templates/`: templates for adding new entries consistently.
- `docs/entries/`: optional detail pages when a resource needs more than a short entry.
- `docs/data-schema.md`: schema reference for `data/entries.yml`.

## Adding New Resources

1. Add the resource to `data/entries.yml` (see `docs/data-schema.md` for the schema).
2. Run `python3 scripts/generate.py` to regenerate the category pages.
3. Commit `data/entries.yml` together with the regenerated pages.
4. If an item needs longer notes, create a dedicated page under `docs/entries/` using the template in `docs/templates/entry-template.md` and link to it from the entry's `url`.

Detailed editing guidance lives in [docs/contributing.md](docs/contributing.md).

## Browse Site

The browse site is built from `data/entries.yml` by `scripts/generate.py` (stdlib only) and deployed to GitHub Pages on every push to `main` (see `.github/workflows/pages.yml`).
